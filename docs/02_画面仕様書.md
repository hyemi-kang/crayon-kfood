# 画面仕様書

単一ページ（`/`）。画面全体が木の机の上のスケッチブックで、6 枚のページ（表紙 + 5 ページ）を 1 つの pin ステージ内で切り替える。

## 1. 画面構成

| 順 | key | 付箋ラベル | 付箋色 | 内容 |
|---|---|---|---|---|
| 0 | cover | 表紙 | `#c9a26b` | タイトル「韓国ごはん スケッチブック」。クラフト紙の表紙 |
| 1 | bibimbap | ビビンバ | `#f59a23` | ビビンバの紹介 |
| 2 | tteokbokki | トッポッキ | `#e8483a` | トッポッキの紹介（湯気は MorphSVG で揺らす） |
| 3 | samgyeopsal | サムギョプサル | `#f4a6a0` | サムギョプサルの紹介 |
| 4 | draw | おえかき診断 | `#ffd23f` | お絵かきキャンバス + 味選択 + 診断結果 |
| 5 | contact | ご連絡 | `#3a8fd9` | 連絡先（サンプル）+ 入力フォーム + 送信演出 |

共通要素: 木目の机の背景 / 上綴じのスパイラル（`SpiralBinding`）/ クレヨン風 SVG フィルター（`CrayonFilters`）/ 右端の付箋ナビ（`PageTabs`、md 以上のみ）/ クレヨンカーソル（マウス端末のみ）。

## 2. 画面遷移・スクロール挙動

1. 読み込み → ローダー（0〜100%）→ 紙がめくれて表紙 → 表紙イントロ。ここまでスクロール不可。
2. イントロ終了後にスクロールを解除し、`ScrollTrigger.refresh()` で pin 幅・開始/終了位置を測り直す。
3. スクロール量に応じてタイムラインが進む（`scrub: 0.8`、タイムライン 1 単位 = 110px）。各ページの描画アニメ → 上辺を軸に 118° 奥へめくれて次ページ、を繰り返す。
4. 付箋クリックで、該当ページの着地位置へ 2.2 秒かけてスクロール（Lenis 優先、なければ `window.scrollTo`）。
5. 現在ページは、スクロール位置から求めた時刻で判定し、付箋の強調表示に反映する。

## 3. おえかき診断ページ

| 要素 | 仕様 |
|---|---|
| キャンバス | 2 枚重ね（確定済みの絵 / 描画中の線）。座標は 0〜1 に正規化して保持し、`ResizeObserver` でサイズに追従。描画は `perfect-freehand` + クレヨンのかすれノイズ（固定シード） |
| 色 | 9 色のラジオボタン |
| 太さ | ほそい 7px / ふつう 16px / ふとい 30px |
| 補助操作 | ひとつ戻す / ぜんぶ消す（絵が無いときは無効） |
| 味キーワード | 11 種から最大 3 つ。上限を超えて選ぶと「えらべるのは3つまでだよ」を表示 |
| 診断ボタン | 「この絵でさがす ✎」。絵が無い間は無効で「まずは絵を描いてね」を表示。押すと「さがし中」表示のあと結果 |
| 結果 | 「あなたの絵の色」バー → 上位 3 件のカード（順位・料理名・ハングル・一致度%・バー・理由タグ）。1 位のみ「いちばん近い一皿！」バッジ、紹介文、「この料理の色」バーも表示 |
| 絵が少ない場合 | 案内メッセージのみ表示（結果なし） |
| 注意書き | 「遊びの診断です。絵は端末の外には送られません。」 |

## 4. ご連絡ページ

状態遷移: `idle`（入力中）→ `sending`（演出中）→ `done`（お礼表示）→ `resetting`（巻き戻し）→ `idle`

| 状態 | 画面 | 操作可否 |
|---|---|---|
| idle | 見出し・連絡先・フォーム・注意書き | 入力・送信可 |
| sending | 手紙が破れる→畳まれる→紙飛行機に折られる→クレヨンの軌跡を描いて飛んでいく（約 6〜7 秒） | 入力欄無効、スクロールロック |
| done | 「お便り、飛んでいきました！」+ 控え（名前・連絡先・ご意見）+ 星 + 「もう一枚書く」 | 「もう一枚書く」のみ |
| resetting | 2 倍速で巻き戻し | 全て無効、スクロールロック |

バリデーションメッセージ:
- 連絡先が空: 「メールアドレスか電話番号を書いてね。」
- ご意見が空: 「ご意見・ご質問を書いてね。」
