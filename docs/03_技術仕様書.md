## 3. 設計方針

### 3.1 ページ = コンポーネント + ビルダー関数
各ページは「見た目のコンポーネント」と「タイムラインに自分の区間を足す `build○○(tl, root, at)` 関数」をセットで export する（`PageBuilder` 型）。戻り値は区間の終了時刻。`Sketchbook.tsx` が `at` を繋いで 1 本のマスタータイムラインに連結する。

### 3.2 ページめくり
- 各ページを `data-flip` の 3D コンテナ（`perspective: 2400`）に入れ、表面/裏面を `backface-visibility: hidden` で持つ。
- `flip()` が `rotateX: -118`（transformOrigin 上辺）+ 影の濃淡を tween。完了時に `autoAlpha: 0`。

### 3.3 スクロールのロック
`setScrollLocked(on)`（`lib/lenis.ts`）に集約。Lenis は `window.scrollTo` で動かすため、`lenis.stop()` と `overflow: hidden` の**両方**をかける。ローダー〜表紙イントロ、送信演出中に使用。Lenis 生成前に要求されても状態を覚えておき、生成時に適用する。

### 3.4 スクラブと時間再生の使い分け
- ページ内容の描画・めくり: スクロール連動（scrub）
- ご連絡の送信演出: スクロールと独立した**時間再生**のタイムライン（`paused: true`）。pin 位置がずれないよう再生中はスクロールをロック

### 3.5 おえかき診断のデータ設計
- ストローク座標は 0〜1 の正規化値で保持（リサイズ耐性）。
- 判定ロジック（`lib/analyze.ts`）は料理データ（`lib/dishes.ts`）と分離。料理の追加・調整は `DISHES` の編集で行える。

## 4. 静的書き出し・公開

`next.config.ts`:
- `output: "export"` → `npm run build` で `out/` に静的ファイルを出力。
- `basePath: process.env.PAGES_BASE_PATH` → GitHub Pages のプロジェクトページ（`/<リポジトリ名>/`）用。ローカルでは未設定で `/`。
