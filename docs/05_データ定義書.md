# データ定義書

定義元: `lib/dishes.ts`（おえかき診断で使うデータ）。いずれもコード内の定数で、DB・外部ファイルは使わない。

## 1. クレヨン色パレット（`PALETTE`）

| key | 表示名 | hex | RGB |

| red | あか | `#e8483a` | 232, 72, 58 |

診断では、描かれた各画素を RGB の二乗距離が最も近いパレット色に分類する。

## 2. 味キーワード（`TASTES`、11 種）

辛い / 甘い / しょっぱい / 酸っぱい / あっさり / こってり / 香ばしい / 温かい / 冷たい / もちもち / シャキシャキ

選択できるのは最大 3 つ（`MAX_TASTES`）。

## 3. 料理データの型（`Dish`）

| フィールド | 型 | 意味 |
|---|---|---|
| id | string | 識別子 |
| name | string | 日本語名 |
| hangul | string | ハングル表記 |
| blurb | string | 紹介文（1 位のカードに表示） |
| colors | `Partial<Record<ColorKey, number>>` | 色の割合（合計およそ 1） |
| shape.aspect | number | 横長さ（幅/高さ） |
| shape.fill | number（0〜1） | 描いた範囲内の塗りの詰まり具合 |
| shape.elong | number（0〜1） | 細長さ（0=丸い、1=細長い） |
| taste | `Partial<Record<Taste, number>>` | 味の特徴（0〜1） |

## 5. 診断で算出する特徴量（`Features`）

| 名前 | 意味 |
|---|---|
| colors | 描かれた部分の中での 9 色の割合 |
| coverage | キャンバス全体に対する塗りの割合（約 1.2% 未満は「絵が少ない」） |
| aspect | 描いた範囲の 幅/高さ |
| fill | 描いた範囲の中の詰まり具合 |
| elong | 細長さ（座標の共分散の固有値比から算出） |

## 6. スコア計算（`lib/analyze.ts`）

| 要素 | 計算 |
|---|---|
| 色 | 絵と料理の色配合のコサイン類似度 |
| 形 | aspect（対数、σ=0.5）×0.4 + fill（σ=0.28）×0.3 + elong（σ=0.35）×0.3。各項はガウス関数 |
| 味 | 選んだ味キーワードに対する料理の値の平均（未選択なら使わない） |
| 総合 | 味なし: 色×0.68 + 形×0.32 ／ 味あり: 色×0.4 + 形×0.2 + 味×0.4 |
| 表示 | 上位 3 件、一致度は `min(0.99, score)` を % 表示 |

## 7. 料理を追加するとき

`DISHES` に `Dish` を 1 件追加する。`colors` はパレットの key のみ使い、合計がおよそ 1 になるようにする。味は `TASTES` にある語のみ使う（型で検査される）。
