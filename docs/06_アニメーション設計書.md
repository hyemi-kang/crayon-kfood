# アニメーション設計書

## 1. 全体構成

| 種類 | 駆動 | 場所 |
|---|---|---|
| ローダー | 時間再生（ループ + カウンター） | `components/Loader.tsx` |
| 表紙イントロ | 時間再生（1 回） | `CoverPage.tsx` の `playCoverIntro` |
| ページ内容・ページめくり | スクロール連動（scrub） | `Sketchbook.tsx` のマスタータイムライン |
| 送信演出 | 時間再生（`paused: true` を `play(0)` / `reverse()`） | `ContactPage.tsx` |
| クレヨンカーソル | マウス移動（`quickTo`） | `CrayonCursor.tsx` |
| 診断結果カード | 結果表示時に再生 | `DrawPage.tsx` |

## 2. 使用プラグイン（`lib/gsap.ts` で一括登録）

| プラグイン | 用途 |
|---|---|
| ScrollTrigger | pin + scrub でステージを固定し、スクロールでタイムラインを進める |
| DrawSVG | 線が描かれていく表現、紙の折り目、飛行機の軌跡 |
| MorphSVG | トッポッキの湯気の揺れ、紙飛行機の形（四角→折った形→飛行機） |
| MotionPath | 紙飛行機が軌跡に沿って飛ぶ |
| SplitText | 表紙タイトル・ご連絡の見出しを 1 文字ずつ出す |
| CustomEase | `crayon` イージングの登録 |
| `@gsap/react`（`useGSAP`） | スコープ付きの生成とクリーンアップ |

## 3. マスタータイムライン（`Sketchbook.tsx`）

- ScrollTrigger: `trigger=wrap`、`start: "top top"`、`end: +=(タイムライン長 × 110px)`、`pin=stage`、`scrub: 0.8`、`anticipatePin: 1`、`invalidateOnRefresh: true`。
- 連結順: `buildCover` → `flip(0→1)` → `buildBibimbap` → `flip(1→2)` → `buildTteokbokki` → `flip(2→3)` → `buildSamgyeopsal` → `flip(3→4)` → `buildDraw` → `flip(4→5)` → `buildContact` → 余白 0.6。
- 各ページ区間の開始は直前のめくり終了 + 0.1。めくり開始は直前ページの終了 + 0.2〜0.3。
- ラベル（key 名）を各ページの開始時刻に付与。付箋ナビの現在ページ判定と着地位置に使う。
- 着地位置: おえかき診断は `drawEnd - 0.4`、ご連絡は `contactEnd - 0.4`、他は開始 + 0.2（表紙は 0）。

### ページめくり `flip()`（所要 1.8 単位）

| 対象 | 動き |
|---|---|
| めくるページ | `rotateX: -118`、transformOrigin `50% 0%`、`power2.in` |
| めくるページの影 | `opacity 0→1` |
| 次ページの落ち影 | `opacity 1→0`（`power1.out`） |
| 完了時 | めくったページを `autoAlpha: 0` |

## 4. ページ別の見せ場

| ページ | 内容 |
|---|---|
| 表紙 | タイトルを SplitText で 1 文字ずつ表示。スクロール区間では表紙の要素を退場させる |
| ビビンバ | 見出し → 具材のラベルと引き出し線 → 渦巻きで混ぜる軌跡（`spiralPath`）→ 混ざった絵に切り替え → 湯気 |
| トッポッキ | 見出し → ゲージが段階的に塗られる → 湯気を MorphSVG で繰り返し揺らす |
| サムギョプサル | 見出し → 炎の揺らぎ → 焼き色 → 火花 → ニンニク・サンチュが現れ、葉が拡縮 |
| おえかき診断 | 見出し・キャンバス・パネルが順に現れ、操作できるよう 0.8 の余白を置く |
| ご連絡 | 見出しを 1 文字ずつ → 下線を DrawSVG → 連絡先 → フォーム各項目 → 注意書き、のあと 0.8 の余白 |

## 5. 共通ヘルパー（`lib/crayon.ts`）

| 関数 | 役割 |
|---|---|
| `drawStroke(tl, paths, at, dur, {crayon, color, ease})` | DrawSVG で線を描きつつ、クレヨン先端を線の先頭に追従させる。scrub の逆再生でもなぞり戻る |
| `hideCrayon` | ページ切替前にクレヨンを消す |
| `popIn` | 手書きラベルを下から「ぽん」と出す（`back.out(2.4)`） |
| `spiralPath` | 渦巻き状のパス生成 |
| `zigzag` | 色塗り用のジグザグ線 |
| `seeded` | 固定シードの擬似乱数（SSR とクライアントで値を揃える） |
| `PageBuilder` 型 | `(tl, root, at) => 終了時刻` |

## 6. 送信演出（`ContactPage.tsx`、通常速度で約 6〜7 秒）

| 段階 | 所要 | 動き |
|---|---|---|
| 1. 破る | 0.8 | 手紙の上端が `clip-path` でギザギザになり、少し浮いて震える |
| 2. 畳む | 1.0 | 手紙が 0.3 倍に縮み、飛行機の元の四角形に切り替わる |
| 3. 折る | 2.0 | MorphSVG で 四角 → 三角に折る → 飛行機。折り目を DrawSVG で描く |
| 4. 飛ぶ | 2.8 | MotionPath で軌跡に沿って飛び、軌跡を DrawSVG で描いて消す |
| 5. お礼 | 4 の途中から | 下の紙にお礼文・控えを順に表示し、星を `popIn` で出して回転 |

- `clip-path` の頂点数を揃えて tween できるようにしている（`N = 26`）。
- 完了で `done`、巻き戻し完了で初期化（入力値クリア）。どちらもスクロールロックを解除する。

## 7. スクロールロックとの関係

| 場面 | ロック | 解除 |
|---|---|---|
| ローダー〜表紙イントロ | `Loader` が開始時にロック | イントロ完了（または `duration + 1` 秒の保険）で解除し、`ScrollTrigger.refresh()` |
| 送信演出・巻き戻し | 再生開始時にロック | 完了時 / アンマウント時に解除 |

## 8. 動きを減らす設定（`prefers-reduced-motion: reduce`）

| 対象 | 挙動 |
|---|---|
| ローダー | 表示せず即完了 |
| Lenis | 生成しない（通常のスクロール） |
| 送信演出 | `timeScale(20)` で高速再生 |
| CSS | `scroll-behavior: auto` |

## 9. 実装上の注意

- 色塗りの線は、長さ 0 のとき丸い線端が点に見えるため、描き始めるまで非表示にする（`drawStroke`）。
- 現在ページは `tl.time()`（scrub で遅れる）ではなく、`progress × duration` から求める。
- ローディング中はスクロールバーが無く、解除してもリサイズが起きないため、解除後に `ScrollTrigger.refresh()` を呼んで測り直す。
