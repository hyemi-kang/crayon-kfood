# 要件定義書 — 韓国ごはん スケッチブック

| 項目 | 内容 |
|---|---|
| プロジェクト名 | food-ad（韓国ごはん スケッチブック / 한식 스케치북） |
| 版 / 更新日 | 1.0 / 2026-10-08 |
| 対象 | 現時点で実装済みの機能のみ（未実装の機能は記載しない） |

## 1. 目的・位置づけ

- 韓国料理を紹介する、**GSAP アニメーションの練習用サイト**。
- サイト全体を「1冊のクレヨン画のスケッチブック」に見立て、スクロールでページがめくれ、絵が描き進む体験を作る。
- 練習用のため、**入力内容は送信・保存しない**（§5 参照）。

## 2. 前提・制約

| 区分 | 内容 |
|---|---|
| 表示言語 | 日本語（`<html lang="ja">`）。料理名にはハングルを併記 |
| 配信形態 | 静的サイト（`output: "export"`）。サーバー処理・DB・外部 API は使わない |
| 公開先 | GitHub Pages（main への push で自動公開） |
| 対象端末 | モダンブラウザ（PC を主、タッチ端末でも動作）。付箋ナビは md 以上の幅のみ表示 |
| 社内環境 | npm / next の通信は社内 SSL 検査の影響を受ける（`NODE_OPTIONS=--use-system-ca` を付ける。[開発環境・運用手順書](04_開発環境・運用手順書.md) 参照） |

| F-04 | 料理紹介ページ（3 枚） | ビビンバ・トッポッキ・サムギョプサルを、クレヨン風の絵が描かれていくアニメーションで紹介 | `pages/*Page.tsx` |

### 3.1 おえかき診断（F-06）の詳細要件

- **入力**: クレヨン 9 色（あか・だいだい・きいろ・みどり・あお・ちゃいろ・ピンク・しろ・くろ）、線の太さ 3 段階（ほそい／ふつう／ふとい）、味キーワード 11 種（辛い・甘い・しょっぱい・酸っぱい・あっさり・こってり・香ばしい・温かい・冷たい・もちもち・シャキシャキ）から最大 3 つ。
- **操作**: 「ひとつ戻す」「ぜんぶ消す」。マウス・指のどちらでも描ける。絵が無い間は「この絵でさがす」を押せない。
- **判定**: 端末内のルールベース。AI・外部 API は使わない。
  - 絵を 96×72 に縮小し、各画素を最も近い 9 色に分類して「色の割合」「塗りの割合」「縦横比」「詰まり具合」「細長さ」を算出。
  - 料理 14 種（ビビンバ、トッポッキ、サムギョプサル、キムチチゲ、プルコギ、チャプチェ、サムゲタン、ヤンニョムチキン、冷麺、キンパ、スンドゥブチゲ、パジョン、ホットク、パッピンス）の定義と比較。
  - スコア = 味未選択: 色 0.68 + 形 0.32 ／ 味選択あり: 色 0.4 + 形 0.2 + 味 0.4。表示の一致度は最大 99%。
- **エラー**: 描き込みが少ない（塗りが全体の約 1.2% 未満）場合は「まだ絵が少ないみたい。もう少し大きく描いてね！」と案内し、結果は出さない。

### 3.2 ご連絡フォーム（F-07）の入力仕様

| 項目 | 必須 | 最大文字数 | 備考 |
|---|---|---|---|
| お名前 | 任意 | 40 | 入力時はお礼文に「○○さん」と表示 |
| メールアドレス または 電話番号 | 必須 | 80 | 形式チェックはしない（空欄のみエラー） |
| ご意見・ご質問 | 必須 | 400 | 控えでは 4 行まで表示 |

- 未入力時はエラー文を表示し、送信演出は始めない。
- 演出中（送信中・巻き戻し中）は入力欄を無効化し、スクロールをロックする。

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| アクセシビリティ | `prefers-reduced-motion: reduce` の環境ではローダーを省略、Lenis を無効化、送信演出を 20 倍速で再生。キャンバス・色選択・太さ選択・ナビ・フォームに `aria-label` / `role` を付与。診断結果は `aria-live="polite"`、フォームエラーは `role="alert"` |
| レスポンシブ | 文字サイズは `clamp()` で可変。ステージは画面高（`100svh`）に収める |
| フォント | `@fontsource/*`（Yusei Magic / Hachi Maru Pop / Gaegu）でバンドル。Google Fonts などの外部取得は使わない（社内 SSL 検査による取得失敗を避けるため） |
| 品質 | TypeScript strict、ESLint（`eslint-config-next`）で静的検査 |

## 5. 個人情報（PII）の取り扱い

- ご連絡フォームは**練習用**で、入力内容はどこにも送信・保存されない（画面にも注意書きを表示）。
- ただし、利用者が氏名・メール・電話番号を入力できる画面のため、**本物の個人情報は入力しない**運用とする。
- 画面内の連絡先（`hello@hansik-sketch.example`、`03-1234-5678`、住所、Instagram）はすべて**架空のサンプル**。
- おえかき診断の絵はブラウザ内で処理され、外部へ送信されない。
